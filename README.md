# 📱 Mobile Sales Dashboard \| Power BI

## 📌 Project Overview

This project is an interactive Mobile Sales Dashboard created using
Microsoft Power BI. It provides insights into mobile sales performance,
customer ratings, transactions, payment methods, and brand-wise sales.

## 🛠️ Tools & Technologies

-   Microsoft Power BI
-   Data Visualization
-   Interactive Dashboard & Filters

## 📊 Dashboard Features

**1. Key Performance Indicators (KPIs)**

-   Total Quantity
-   Total Sales
-   Average Sales
-   Total Transactions

**2. Sales Analysis**

-   Total Quantity by Day
-   Sales by Weekday
-   Total Sales by Mobile Model

**3. Brand Analysis**

-   Brand-wise Total Sales
-   Brand-wise Quantity
-   Brand-wise Transactions

**4. Payment Method Analysis**

-   Transactions by Credit Card
-   Debit Card
-   UPI
-   Cash

**5. Customer Analysis**

-   Customer Ratings Analysis

**6. Geographical Analysis**

-   Location-wise Sales Distribution using Map Visualization

## 🎛️ Interactive Filters

-   Month (January--December)
-   Mobile Model
-   Payment Method
-   Day Name
-   Brand
